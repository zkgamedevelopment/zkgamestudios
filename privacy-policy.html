3.2 PlayFab

PlayFab is a backend platform for live games that provides services such as player authentication, data storage, analytics, and multiplayer features. The app integrates PlayFab to enable user login, progression tracking, and online multiplayer functionalities.

Personal Data collected by PlayFab may include:

  • Device information (type, OS version)
  • IP addresses
  • Game activity data (e.g. session duration, achievements, inventory)

Retention:

PlayFab retains user data for as long as necessary to provide services and may anonymize data after a set period. Users can request data deletion by contacting the developer.
